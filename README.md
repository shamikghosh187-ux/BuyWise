# BuyWise

**Buy better. Know why.**

BuyWise is an AI-powered shopping intelligence platform designed to help people discover, compare and evaluate products before buying.

## Current build

This first frontend milestone includes:
- Product discovery with search and category filters
- Product cards with price and rating presentation
- Watchlist interactions
- Compare shortlist selection
- Sort by featured, price and rating
- Responsive desktop and mobile layout

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important data note

The current catalogue is illustrative sample data. Prices, ratings and offers are not live retailer data. Live product feeds, source attribution, price history and AI purchase analysis are planned integration stages.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
