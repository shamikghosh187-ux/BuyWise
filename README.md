# BuyWise

**Buy better. Know why.**

BuyWise is a shopping-intelligence MVP designed to help people discover, compare and evaluate products before buying.

## Current experience

- Search products by name, brand, category or description
- Filter the catalogue by category
- Sort by recommended score, price or rating
- Open product detail panels with key specifications
- Save products to a browser-persisted watchlist
- Compare up to three products side by side
- Responsive desktop and mobile interface

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Data transparency

The current catalogue is illustrative sample data. Prices, ratings, specifications and value indicators are not live retailer information and are not verified offers. This MVP does not yet connect to retailer APIs, verify sellers or stock, track real price history, or process purchases. Always confirm product information with a retailer before buying.
